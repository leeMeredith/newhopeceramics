# New Hope Ceramics

The studio site for New Hope Ceramics by Lee Meredith. Plain HTML, CSS and
JavaScript with no build step.

- `index.html` is the only page. Everything on it is built from `js/pieces.js`.
- **To add a piece:** add one entry to `js/pieces.js` and put its photos in `media/img/<Kind>/`.
- Photos are web-sized (1600px longest side, camera and location data removed),
  with a smaller `.webp` copy beside each one that browsers load first.
- `PHOTOS-TO-SORT.md` lists photos the old page asked for that are missing, and
  uploaded photos not placed in any piece yet.

Buying is by email or Facebook for now.
